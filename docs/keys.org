* Where the keys come from
  Sublime loads a package's key bindings from =Default.sublime-keymap= and
  =Default (Windows|OSX|Linux).sublime-keymap=. OrgEverywhere has only the
  first, so its keys are the same on every platform: =alt+o= is =alt+o= on
  macOS too (option+o), not =cmd+o=. These are the /default keys/ listed
  below. (The package also contains an =OrgEverywhere.sublime-keymap=; Sublime
  does not load a file by that name, so its bindings do nothing.)

  Most keys are a chord: =alt+o= followed by one or more letters. =alt+o i h=
  means press =alt+o=, let go, press =i=, then =h=. Almost all of them only
  work in an org file (or the view named in the heading of the table).

  To change a key, open *Preferences > Package Settings > Org Everywhere > Key
  Bindings*: OrgEverywhere's bindings are on the left, yours on the right.
  Copy a line across and change its =keys=. Every command, bound or not, is
  also in the command palette under its caption (*Org ...*).

* In an org file
** Tab, enter and the "do what I mean" keys
   | Keys               | Command                    | What it does                                                         |
   |--------------------+----------------------------+----------------------------------------------------------------------|
   | =tab=              | =org_tab_cycling=          | fold or unfold the heading, drawer, link or checkbox at the cursor; before the first heading, cycle the whole file; in a table, next cell |
   | =shift+tab=        | =org_global_tab_cycling=   | on a heading: cycle the whole file (overview, contents, show all)    |
   | =enter=            | =org_open_link=            | on a link: follow it                                                 |
   | =enter=            | =org_enter_on_heading=     | on a heading: new line, indented to the heading's body               |
   | =ctrl+enter=       | =org_generic_insert=       | new list item, checkbox, numbered item or sibling heading, after this one |
   | =ctrl+shift+enter= | =org_generic_insert_aux=   | the same at the end of the list, or a child heading                  |
   | =alt+o t=          | =org_toggle=               | toggle the checkbox, or change the todo state                        |
   | =alt+o c c=        | =org_recalc=               | run the block or table at the cursor, or recalculate checkbox summaries and numbered lists |

* In orgs result views
  The views orgs commands open (habits, clock report, full text search
  results, file history...):

  | Keys    | Command                  | What it does                     |
  |---------+--------------------------+----------------------------------|
  | =enter= | =org_orgs_goto_row=      | open the heading or line         |
  | =g=     | =org_orgs_refresh_view=  | ask the server again             |
  | =t=     | =org_orgs_habit_toggle=  | mark the habit done today        |

  In the tag and id inputs that offer completions, =up= and =down= move
  through the suggestions.

* With NeoVintageous
  If you use [[https://github.com/NeoVintageous/NeoVintageous][NeoVintageous]],
  a second set of bindings works in command (normal) mode with =space= as
  the leader in place of =alt+o=: =space i h= inserts a sibling heading,
  =space c i= clocks in, and so on for every =alt+o= key above, plus:

  | Keys            | Command                              |
  |-----------------+--------------------------------------|
  | =Z=             | =org_capture=                        |
  | =shift+space=   | =org_agenda_day_view=                |
  | =R=             | =org_refile=                         |
  | =space i m=     | =org_insert_tag=                     |
  | =space r m=     | =org_remove_tag=                     |
  | =space r a m=   | =org_remove_all_tags=                |
  | =space r f=     | =org_refile_to_file=                 |
  | =space r r=     | =org_refile_to_file_and_headline=    |
  | =space f o=     | =org_fold_all_but_me= (fold the rest) |
  | =space f m=     | =org_fix_tags=                       |
  | =space f s=     | =save=                               |
  | =space 1= ... =space 5= | focus editor group 1 to 5    |
  | =space t e=     | =org_edit_formula_for_cell= (table)  |
  | =space t k=     | =org_clear_cell= (table)             |

  In the agenda in command mode =t= changes the todo state (=s= without
  NeoVintageous), and =f f= reopens the filter view.

* Unbound commands
  Many commands have no key: the folding commands (*Org Fold All*,
  *Org Unfold All*...), *Org Jump In File*, *Org Insert Property*,
  *Org Sort List*, *Org Insert Tag* and most of the orgs commands. Run them
  from the command palette, or give them keys of your own:

  #+BEGIN_SRC js
  // Packages/User/Default (OSX).sublime-keymap (or Windows / Linux)
  [
      { "keys": ["alt+o", "j"], "command": "org_jump_in_file",
        "context": [{ "key": "selector", "operand": "text.orgmode" }] },
      { "keys": ["alt+o", "i", "g"], "command": "org_insert_tag",
        "context": [{ "key": "selector", "operand": "text.orgmode" }] },
  ]
  #+END_SRC
