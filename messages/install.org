* Welcome to Org Everywhere

  Org Everywhere is a fork of [[https://github.com/ihdavids/orgextended][OrgExtended]] that uses the
  [[https://github.com/ihdavids/orgs][orgs]] server for everything that spans more than one file:
  the agenda, clocking, capture, refile and archive, ids and backlinks, search
  and exporting. Editing a buffer (folding, todo cycling, tables, lists, source
  blocks...) happens in Sublime, as before.

  Because orgs is shared, Sublime, VSCode, the orgs command line and worg (the
  web front end orgs serves) all see the same notes at the same time.

** OrgExtended and Org Everywhere cannot both be enabled
   They handle the same files and commands and will fight over them. If
   OrgExtended is installed, Org Everywhere offers to disable it when Sublime
   starts. You can also do it yourself: *Package Control: Disable Package*,
   then pick OrgExtended.

** Getting started
   1. Restart Sublime once Package Control has finished installing the
      dependencies (pyyaml, dateutil, requests, regex, six).
   2. Run *Org: Set Up a Local orgs Server*. It downloads orgs, runs it on
      this machine reading a folder of org files you pick, and logs you in
      to it. No server to install and no password to type.
   3. Or point Org Everywhere at an orgs server you already run with
      *Org: Set orgs server url* (it looks at http://localhost:8010 and
      https://localhost:443 by default).
   4. *Org: orgs connection status* shows what is going on, and the status
      bar of an org file shows the connection.

   Without a server, editing still works; features that need the server say
   that it is not connected.

** Requirements
   Sublime Text build 4205 or later: Org Everywhere runs on the Python 3.14
   plugin host.
